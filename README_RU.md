# Зимний апокалипсис — Minecraft Forge 1.20.1

## Сборка
Нужны Java 17 и интернет для загрузки Gradle/Forge:
- Linux/macOS: `./gradlew build` (добавьте Gradle Wrapper через установленный Gradle)
- Windows: `gradle build`

Готовый JAR появится в `build/libs/`.

## Что реализовано в этой первой версии
- Ядро холода автоматически появляется на расстоянии 10–100 блоков от мирового спавна.
- Ядро распространяет снег и превращает воду в лёд.
- С каждым игровым днём радиус, количество попыток и частота распространения увеличиваются.
- Температура игрока показывается в action bar (над панелью быстрого доступа).
- Температура зависит от игрового дня, близости ядра и температуры биома; при сильном переохлаждении игрок получает урон от замерзания.

## Важно
Это исходный проект первой рабочей версии, а не проверенный готовый JAR: перед публикацией необходимо собрать его в GitHub Actions и проверить в игре. Для блока ядра пока не добавлена PNG-текстура — временно будет видна текстура отсутствующего ресурса. Добавьте файл `src/main/resources/assets/winter_apocalypse/textures/block/cold_core.png` размером 16×16 или 32×32.

# Зимний апокалипсис — Minecraft Java 1.20.1 / Forge 47

## Новое в версии 1.1.0
- Снежный охотник: враждебный зомби-монстр обычного роста, появляется на заснеженной местности в темноте и замедляет игрока при ударе.
- Ледяной великан: редкий монстр высотой 4,2 блока, 110 здоровья, сильный удар и длительное замедление.
- Мастер зимы: редкий торговец на холодных территориях с меховой и арктической одеждой, печью, печатью холода и морозными кристаллами.
- Два комплекта брони: меховой (теплее кожи) и арктический (сильная защита от холода и метели).
- Зимняя печь: светится и согревает игрока в радиусе 6 блоков.
- Печать замедления холода: использовать ПКМ по ядру холода. До 3 уровней; каждый уровень уменьшает радиус и скорость распространения.
- Сохранены ядро холода, снежное распространение и температура игрока.

## Сборка через GitHub
1. Распаковать архив.
2. Загрузить ВСЁ содержимое папки `winter_apocalypse` в корень своего GitHub-репозитория (включая `.github`).
3. Открыть Actions и запустить `Build Winter Apocalypse`.
4. Скачать `winter-apocalypse-1.20.1` в Artifacts.

Требуется Java 17. Это исходный код, который нужно собрать в GitHub Actions и проверить в игре. В текущей версии модели новых существ используют ванильную модель зомби, а мастер зимы — модель странствующего торговца; отдельные авторские 3D-модели ещё не добавлены.
